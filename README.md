# رستا (Rasta) | وب‌سایت معرفی و دانلود اپلیکیشن ترک عادت

وب‌سایت رسمی معرفی و دانلود اپلیکیشن **رستا (Rasta)** — همراه هوشمند، آفلاین و امن شما در مسیر ترک عادات ناخواسته.

## ✨ امکانات اصلی اپلیکیشن
- 🗓 **پشتیبانی از تقویم شمسی**
- 🔒 **۱۰۰٪ آفلاین و حفظ حریم خصوصی**
- 💰 **محاسبه پس‌انداز مالی و بهبود سلامت**
- 🏆 **مدال‌ها و دستاوردهای انگیزشی**
- 🧘 **اورژانس مهار وسوسه (تمرین تنفس ۴-۷-۸)**
- 📓 **دفترچه و یادداشت روزانه**

## 📁 ساختار پروژه
```
├── index.html            # صفحه اصلی لندینگ
├── favicon.ico           # فاوآیکون ریشه
├── site.webmanifest      # مانیفست وب‌اپلیکیشن (PWA)
├── robots.txt            # فایل راهنمای موتورهای جستجو
├── sitemap.xml           # نقشه سایت
└── assets/
    ├── css/
    │   └── style.css     # استایل‌های سفارشی و ریسپانسیو
    ├── js/
    │   └── main.js       # اسکریپت‌ها و تعاملات لندینگ
    └── images/           # لوگوی برنامه، نشان مارکت‌ها، آیکون‌ها و فاوآیکون‌ها
```
